Camera REST API

Take a snapshot from one camera. Receive the JPEG directly, or save it and receive a link to the image.

How it works

Use whiteboard or robot for {camera_id}. The API base is https://lab.bpm.in.tum.de/cameras.

1) Return the image directly

Each GET takes the current picture and returns image/jpeg. The image is not saved to the server and has no HISTORY entry.

GET /api/v1/cameras/{camera_id}/snapshot.jpg

2) Save the image and return a link

Put one camera ID in the URL and send an empty POST. The server saves a JPEG and a matching JSON metadata file. The response contains the complete image URL as plain text and in the Location header.

POST /api/v1/cameras/{camera_id}/captures

The filename combines the camera ID with a UTC time to the millisecond, for example whiteboard_20260926T184527973Z. The same name with .json retrieves its metadata. Saved files are automatically deleted after 2 days (cleanup runs on startup and hourly).

GET /api/v1/captures/{camera_id}_{timestamp}.jpg
GET /api/v1/captures/{camera_id}_{timestamp}.json

On the server, both files are saved directly inside var/captures/. The timestamp is assigned after the service receives the image (it is not the camera sensor's exposure time).

Saved JSON metadata

Each saved JPEG has a .json file beside it with the same filename prefix. For example, whiteboard_20260926T184527973Z.jpg has whiteboard_20260926T184527973Z.json:

{
  "camera_id": "whiteboard",
  "captured_at": "2026-09-26T18:45:27.973+00:00",
  "filename": "whiteboard_20260926T184527973Z.jpg",
  "size_bytes": 19322,
  "width_px": 1280,
  "height_px": 720,
  "content_type": "image/jpeg"
}

Example - whiteboard

Get a picture directly and write the JPEG to whiteboard.jpg:

curl -fsS 'https://lab.bpm.in.tum.de/cameras/api/v1/cameras/whiteboard/snapshot.jpg' -o whiteboard.jpg

Alternatively, save the picture and print its link:

curl -fsS -X POST 'https://lab.bpm.in.tum.de/cameras/api/v1/cameras/whiteboard/captures'

Response body: a link to the saved JPEG (the timestamp changes for every capture):

https://lab.bpm.in.tum.de/cameras/api/v1/captures/whiteboard_20260926T184527973Z.jpg

Send a GET request to that link to retrieve the saved JPEG:

GET https://lab.bpm.in.tum.de/cameras/api/v1/captures/whiteboard_20260926T184527973Z.jpg

Get its matching JSON metadata by replacing .jpg with .json in that URL:

curl -fsS 'https://lab.bpm.in.tum.de/cameras/api/v1/captures/whiteboard_20260926T184527973Z.json'

The JPEG GET returns 200 OK and image/jpeg; the matching JSON GET returns 200 OK and application/json. To save your own capture locally:

saved_url=$(curl -fsS -X POST 'https://lab.bpm.in.tum.de/cameras/api/v1/cameras/whiteboard/captures')
curl -fsS "$saved_url" -o whiteboard.jpg
